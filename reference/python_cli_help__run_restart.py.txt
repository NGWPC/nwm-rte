usage: run_restart.py [-h] --src_path SRC_PATH --dst_path DST_PATH
                      [--checkpoint_dir CHECKPOINT_DIR]

Restart a default ngen realization from a checkpoint.

options:
  -h, --help : type=None
                        show this help message and exit

  --src_path, -src : type=None default=None
                        Path to the existing run to restart from.

  --dst_path, -dst : type=None default=None
                        Path to the new restart run destination. Defaults to src_path + '_restart'.

  --checkpoint_dir, --cpd : type=None default=None
                        Path to checkpoint state directory. Defaults to <dst_path>/checkpoint/.
