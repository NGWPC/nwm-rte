usage: run_tests.py [-h] [-nofcst] [--quit_forecast_after_forcing_running]
                    [-quitfcdur QUIT_FORECAST_AFTER_DURATION] [-calib]
                    [-quitcaldur QUIT_CALIBRATION_AFTER_DURATION]
                    [-ofuncs OBJECTIVE_FUNCTIONS [OBJECTIVE_FUNCTIONS ...]]
                    [-allofuncs]
                    [-optalgos OPTIMIZATION_ALGORITHMS [OPTIMIZATION_ALGORITHMS ...]]
                    [-alloptalgos] [-allforcings]
                    [-mff MODEL_FORMULATIONS_FILE]
                    [-calfsrcs [CALIBRATION_FORCING_SOURCES ...]] [-cs]
                    [--noop] [--restart] [-delraw] [-delscratch]
                    [-rname FCST_RUN_NAME] [-fstatic FORCING_STATIC_DIR]
                    [-g GAGE_ID]
                    [-gdomain {CONUS,Alaska,Hawaii,Puerto_Rico,GL}]
                    [--hydrofab_file HYDROFAB_FILE] [-n NPROCS]

Script for building and running a series of test
realizations, optionally including calibration, coldstart, and forecasts,
using various forcing configurations and model formulations.

options:
  -h, --help : type=None
                        show this help message and exit

  -nofcst, --skip_forecast : bool-switch(store-true) default=False
                        Provide to skip forecast (for testing calibrations only).
                        Incompatible with --do_all_forcing_configs and --do_coldstart

  --quit_forecast_after_forcing_running : bool-switch(store-true) default=False
                        THIS IS CURRENTLY NOT SUPPORTED, pending updates.
                        Instead of waiting for each forecast to finish,
                        quit after the ngen log file indicates that forcing
                        is running successfully.
                        THIS IS CURRENTLY NOT SUPPORTED.

  -quitfcdur, --quit_forecast_after_duration : type=float default=None
                        Instead of waiting for each forecast to finish,
                        quit after the specified elapsed processing duration in seconds.

  -calib, --do_calibration : bool-switch(store-true) default=False
                        Build and run a calibration before forecasts.

  -quitcaldur, --quit_calibration_after_duration : type=float default=None
                        For calibrations, instead of waiting for the realization
                        to finish, quit after the specified processing duration. Units: seconds.

  -ofuncs, --objective_functions : type=Objective default=[<Objective.kge: 'kge'>]
                        List of objective functions for calibration.

  -allofuncs, --do_all_objective_functions : bool-switch(store-true) default=False
                        For calibration, causes all objective functions to be executed: 
                            'kge', 'nse', 'nnse'
                            'nselog', 'corr', 'rmse'
                            'mae', 'rsr', 'pbias'
                            'lseg_fdc', 'hseg_fdc', 'csi'
                            'far', 'pod', 'pkbias'
                            'pkte', 'evbias', 'none'

  -optalgos, --optimization_algorithms : type=Algorithm default=[<Algorithm.dds: 'dds'>]
                        List of optimization algorithms for calibration.

  -alloptalgos, --do_all_optimization_algorithms : bool-switch(store-true) default=False
                        For calibration, causes all optimization algorithms to be executed: 
                            'dds', 'pso', 'gwo'
                            'none'

  -allforcings, --do_all_forcing_configs : bool-switch(store-true) default=False
                        Run all forcing configurations rather than the default shorter default list.
                        For reference, the default list is: ['short_range', 'standard_ana', 'medium_range_blend'].
                        Incompatible with --skip_forecast.

  -mff, --model_formulations_file : type=None default=None
                        If provided, multiple model formulations will be ran,
                        and this is a file path to a tsv file of the formulations list. If not provided,
                        then the default model formulation will be used: ('noah-owp-modular,cfe-s', False).

  -calfsrcs, --calibration_forcing_sources : type=None default=['aorc', 'nwm']
                        Sources of forcing data for calibration runs. If not provided,
                        then this default will be used: ['aorc', 'nwm'].

  -cs, --do_coldstart : bool-switch(store-true) default=False
                        Causes use_cold_start to be True for all forecasts

  --noop : bool-switch(store-true) default=False
                        Run in noop mode - only verify that the script
                        can import libraries and basic setup, then exit without looking
                        for data or running any workflows.

  --restart : bool-switch(store-true) default=False
                        Run in restart mode. Read existing results json file '/ngen-app/bin/bin_mounted/forecast_tests_results.json'
                        if it exists, and skip indexes that already have a record in it.

  -delraw, --delete_forcing_raw_input_first : bool-switch(store-true) default=False
                        Delete contents of '/ngen-app/data/raw_input' before the run,
                        which forces forcing data to be re-downloaded.

  -delscratch, --delete_scratch_and_mesh_first : bool-switch(store-true) default=False
                        Delete scratch dir and ESMF mesh files before the run,
                        which forces ESMF and NetCDF actions to occur.

  -rname, --fcst_run_name : type=str default='fcst_run1'
                        Forecast run name.

  -fstatic, --forcing_static_dir : type=str default='/ngen-app/data'
                        Directory for static forcing files, used when forcing_provider is 'bmi'.

  -g, --gage_id : type=str default='01123000'
                        Gage ID.

  -gdomain, --global_domain : type=str default='CONUS'
                        Global domain/region of forcing data.

  --hydrofab_file : type=str default=None
                        Path to local hydrofabric gpkg file. If provided, bypasses msw-mgr Icefabric API call.

  -n, --nprocs : type=int default=1
                        Number of processors
