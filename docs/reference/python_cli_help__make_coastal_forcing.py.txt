CLI script to generate gridded atmospheric forcing files for coastal models.

NOTE: This includes a T0 output needed for coastal, in addition to the normal T1+ outputs.
NOTE: The T0 output has identical forcing values as T1.
See comments in ngen-forcing model.py function ``write_t0_output``.
An independent T0 state cannot be reliably computed because several forecast products omit required fields at hour zero and substitute hour one. Examples:

Usage:
    Choose exactly one timing mode:

    * ``--cycle_datetime`` (``-dt``) runs an operational forecast cycle. The
        forcing engine determines the time window from the selected configuration.
    * ``--start_time`` (``-start``) together with ``--end_time`` (``-end``) runs
        an explic`it time window, such as an AORC retrospective run.

Examples:
    python -um ngen_rte.coastal.make_coastal_forcing -dt "2025-09-15 00:00:00" -fconfig standard_ana_hawaii -gdomain Hawaii
    python -um ngen_rte.coastal.make_coastal_forcing -start "2013-07-25 00:00:00" -end "2013-07-26 00:00:00" -fconfig aorc -gdomain Hawaii

options:
  -h, --help : type=None
                        show this help message and exit

  -dt, --cycle_datetime : type=datetime_type default=None
                        Operational forecast cycle; cannot be used with --start_time.

  -start, --start_time : type=datetime_type default=None
                        Start of an explicit time window; requires --end_time.

  -end, --end_time : type=datetime_type default=None
                        End of an explicit time window; requires --start_time.

  -rname, --fcst_run_name : type=None default='coastal_run1'
                        Name used in log messages (default: coastal_run1).

  -fconfig, --forcing_configuration : type=None default=None
                        Installed forcing template name, such as short_range or aorc.

  -gdomain, --global_domain : type=None default='CONUS'
                        Coastal output domain (default: CONUS).

  -lb, --lookback : type=int default=None
                        Analysis-only override for the configured lookback window in minutes. Requires --cycle_datetime.

  -fih, --forecast_input_horizons : type=int default=None
                        Analysis-only uniform override for all configured forecast input horizons in minutes. Requires --cycle_datetime.

  --warm_weights : bool-switch(store-true) default=False
                        Recreate reusable regrid weights one product per subprocess, replacing matching cached weights instead of creating a forcing file. Requires --cycle_datetime.

  --debug_conus_subset : bool-switch(store-true) default=False
                        Use the gauge 01123000 CONUS target-grid subset and isolated output paths. Requires --global_domain CONUS.
